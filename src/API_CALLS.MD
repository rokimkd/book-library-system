### BOOK LIBRARY - API CALLS

#### Authors

        - GET:    /authors/get
        - GET:    /authors/get/{id}
        - POST:   /authors/store
        - PATCH:  /authors/update/{id}
        - DELETE: /authors/delete{id}

#### Books

        - GET:    /books/get
        - GET:    /books/get/{id}
        - POST:   /books/store
        - PATCH:  /books/update/{id}
        - DELETE: /books/delete{id}
        - GET:    /books/search
